## 🧠 AI & Agentic Engineering

I treat AI as a system component rather than a magic prompt box. My work involves designing intelligent multi-agent workflows, custom coding agents, and real-time reporting automation.

**Core Principles:**
- **Encode standards, not prompts:** Turning team conventions into reusable agent skills (e.g., database migration rules, event-consumer error handling).
- **Scope agents to domains:** Agents should own a business domain end-to-end, understanding its rules and cross-team dependencies.
- **Trust through verification:** Claims are checked against source code. Assumptions are stated explicitly, and adversarial review runs before merge.
- **Wire agents to the real stack:** Connecting agents directly to production analytics, observability platforms, and issue trackers.

**What I've Built:**
- **Domain-Scoped Review Agents:** Auditing changes against written business rules, planning work, and flagging blockers in e-commerce domains.
- **Organization-Wide Skill Libraries:** Encoding technical standards (hexagonal architecture, DDD, event sourcing) into agent-readable rules.
- **Agent-Assisted Platform Migrations:** Guided live system migrations in multi-market environments, including relational DB migrations and GDPR automation.
